# RotaLivre — execução
1. Instale Python 3.10+ e execute `python -m pip install notebook`.
2. Na raiz do repositório, execute `python -m notebook dynamic-programming/arquivo.ipynb`.
3. No notebook, selecione Kernel → Restart Kernel and Run All Cells.
4. Confira as rotas de custos 200 e 300 e a mensagem de 9 verificações concluídas.
